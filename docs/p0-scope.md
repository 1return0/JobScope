# JobScope P0范围

## 产品定位

面向学生自己的校园招聘情报RAG。系统摄取企业招聘官网、学校就业网和公开招聘材料，为求职者返回带原文证据的岗位要求查询结果。

系统服务候选人本人，不替企业筛选、排名或淘汰求职者。

## P0功能

1. 摄取HTML、PDF、扫描PDF、DOCX、XLSX和PPTX；
2. 保留页码、标题路径、Sheet/单元格和幻灯片编号；
3. 记录公司、岗位、招聘类型、届别、地点、发布时间和抓取时间；
4. 为招聘页面和附件创建版本快照与稳定Evidence ID；
5. 实现BM25、Dense、RRF和Reranker；
6. 区分岗位必须项、加分项和职责描述；
7. 回答附带证据，信息不足时拒答；
8. 建立黄金集、消融实验、Bad Case和Corpus Snapshot；
9. 为CareerPilot提供只读岗位证据API，P1增加MCP适配。

## P0非目标

- 自动替用户批量投递岗位；
- 为企业评估、排名或淘汰求职者；
- 编造简历经历或将计划能力写成已完成能力；
- 绕过招聘网站访问控制、验证码或服务条款；
- 大模型微调、GraphRAG和分布式训练；
- 生产级多租户或企业级SLA。

## 初始验收

- 五类主要格式均有解析测试；
- 120条以上带来源、抓取时间和内容哈希的岗位快照，覆盖至少8家企业；
- 约1000个可定位回原文的Evidence片段；
- 400条以上结构化岗位要求，区分职责、必须项和加分项；
- 80条以上人工核验问题，覆盖事实、过滤、比较、版本、冲突和拒答；
- 四组检索实验可复现；
- 公司、岗位、届别、版本、拒答和注入测试齐全；
- 任意结论可以定位回招聘原文；
- 完成缓存、限流、超时、降级和熔断测试；
- 使用固定的60请求、并发24场景报告吞吐、P50、P95和错误率；
- 解析、检索和接口测试进入自动化检查。

这些数值是最终验收目标，不是当前已实现能力。在实际生成语料、评测集和实验报告之前，不得写入简历成果。
