# 岗位补强教学规则

每次生成课程前必须完整阅读本文件、`Agent-岗位补强-三天学习计划.md` 及 `Agent-岗位补强-课程游标.md`。

1. 先报独立补充游标，不替换原周次。
2. 从一个具体请求按运行顺序带学生走完整业务链路。
3. 展示链路上的核心真实代码，解释输入、输出、表字段、分支、事务及安全边界；不能只给流程图。
4. 给可点击的准确文件链接，讲清两个项目相同机制和不同组装点，不重复讲已学基础。
5. 速通采用每天一个集中单元，仅单元结束统一三题，批改后推进下一天；原子主题不单独考。题目只能考已经讲过的内容。
6. 单测、真实 Smoke、模型质量评测和生产结论严格区分。开发未完成不能提前生成正式课。
7. 不用前端/运维细节挤占三天后端学习安排。若开发范围必须变更，先修计划并说明原因，不静默扩课。
